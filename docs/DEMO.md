# Agent Action Security Lab: guided demonstration

Controlled proposals, two fictional tenants and sandbox actions. No real messages, refunds or external exports are sent.

## A focused walkthrough

1. **Choose a scenario.**
2. **inspect proposal.**
3. **approve or deny.**
4. **inspect the receipt.**

Pause on the evidence at each decision: payload-bound approvals; replay protection; protected / baseline comparison.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

This is evidence about the tested application boundary. Fixture proposals do not measure how often a live model follows an injection, and the result is not a universal security claim.
